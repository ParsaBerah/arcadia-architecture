# 🏛️ Arcadia - Modern Architecture Studio Website

A clean, minimalist, and fully responsive multi-page website designed for an architecture and interior design firm. This project translates a modern Figma design into functional code using pure HTML, CSS, and Vanilla JavaScript.

## 🔗 Live Demo
> **[Click here to view the live website](https://parsaberah.github.io/arcadia-architecture/)**

## ✨ Features
- **Multi-page Structure:** Includes Home, Projects, About, Services, Journal, and Contact pages.
- **Modern UI/UX:** Clean, minimalist design with a focus on typography and imagery (inspired by premium architecture brands).
- **Fully Responsive:** Adapts beautifully to all screen sizes (Desktop, Tablet, Mobile).
- **Asymmetric Grid Layouts:** Unique masonry-style layouts for the portfolio section.
- **Interactive Elements:** Sticky navbar with scroll effects, hover animations on project cards and team members.
- **No Frameworks:** Built purely with Vanilla CSS and HTML for maximum performance and learning.

## 🛠️ Tech Stack
- **HTML5:** Semantic markup.
- **CSS3:** Custom variables (CSS properties), Flexbox, CSS Grid, and responsive media queries.
- **JavaScript (Vanilla):** For DOM manipulation (e.g., changing navbar styles on scroll).
- **Fonts:** [Google Fonts](https://fonts.google.com/) (Playfair Display for headings, Inter for body text).
- **Icons:** [FontAwesome](https://fontawesome.com/).
